KIBERSKAZ — сайт с широким плеером и бесплатным скачиванием MP3

В каждой карточке песни есть:
- широкий плеер с кнопкой воспроизведения/паузы;
- длинная шкала перемотки;
- текущее время и длительность;
- кнопка «Скачать MP3 бесплатно».

Пути задаются в songs.js, например:
{ title: "Круг", description: "Песня о поступках", url: "songs/krug.mp3", cover: "covers/krug.jpg" }

Положите MP3-файлы в папку songs рядом с index.html. Если файл размещён на другом хостинге, в url укажите прямую публичную ссылку, доступную без входа в аккаунт. Ссылка должна открывать сам MP3, а не страницу просмотра файла.

Фоновая картинка задаётся в index.html в строке:
--page-background: url("covers/background.jpg");

Бесплатные хостинги для публикации:
1. Cloudflare Pages — https://pages.cloudflare.com/ — хороший вариант для статического сайта. В бесплатном тарифе есть ограничение 25 MiB на один файл, поэтому проверьте размер каждого MP3.
2. GitHub Pages — https://pages.github.com/ — подходит для небольшого личного архива; обычно публикация требует загрузить сайт в публичный репозиторий. Учитывайте ограничения по размеру сайта и трафику.
3. Netlify — https://www.netlify.com/ — удобная публикация статических сайтов, но бесплатный тариф имеет лимиты использования.

Важно: музыкальные MP3 могут занимать много места и расходовать трафик при прослушивании и скачивании. Если коллекция вырастет, храните аудиофайлы отдельно от самого сайта и используйте прямые публичные ссылки. Google может индексировать сайт, но появление в поиске не гарантируется автоматически.
